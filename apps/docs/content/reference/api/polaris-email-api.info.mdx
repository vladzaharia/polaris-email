HMAC-authenticated REST surface for polaris-email. All requests are signed with
`X-Polaris-Sig: <hex(HMAC-SHA256(secret, canonical))>` where canonical is
`polaris-api\n<METHOD>\n<path>\n<canonical-query>\n<X-Polaris-Ts>\n<X-Polaris-Nonce>\n<sha256-hex(body)>`.

Webhooks delivered to subscribers (the WebhookEnvelope schema below) are signed
`X-Polaris-Sig: <hex>` over the canonical string
`polaris-webhook\nPOST\n<path>\n<canonical-query>\n<ts>\n<nonce>\n<sha256-hex(body)>`.
Consumers should verify with the SDK (`@polaris-email/sdk-node`'s `verifyWebhook`
or `polariswebhook.VerifyWebhook` from `packages/sdk-go`).
