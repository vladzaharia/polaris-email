v2 webhook envelope delivered to subscribers. The HTTP request carries
`X-Polaris-Sig: <hex>`, `X-Polaris-Ts`, `X-Polaris-Nonce`,
`X-Polaris-Event-Id`, and `X-Polaris-Event` headers. Verify with the SDK
`verifyWebhook` helper.
