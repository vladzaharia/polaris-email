Mail domain — the unit of DNS ownership for inbound (Email Routing
CNAMEs + MX) and outbound (DKIM, SPF, DMARC, MTA-STS, TLS-RPT) email.
Mirrors the `mail_domains` row shape after `services/api/migrations/
0007_mta_sts.sql`. The Phase C MTA-STS + TLS-RPT fields drive
self-hosted policy publishing under `mta-sts.{domain}`; see
`_mta_sts_mode` for the lifecycle states.
