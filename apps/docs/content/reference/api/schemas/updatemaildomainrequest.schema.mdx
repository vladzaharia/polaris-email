Generic patch surface for a mail domain. Note: switching MTA-STS state
end-to-end (DNS + KV + DB) is normally routed through the dedicated
lifecycle endpoints — `POST .../mta-sts/{enable,disable,promote}`
so the publish side-effects fire. The fields here are accepted by
bulk operator scripts that have already manually staged the records.
